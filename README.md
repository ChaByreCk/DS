# Discord Mobile Manager (Android)

Лёгкий нативный Android-проект на Kotlin для хранения списка профилей Discord.

## Возможности текущей версии
- Добавление и удаление профилей (до 100 записей).
- Название голосового канала для каждого профиля как заметка.
- Локальное сохранение списка.
- Открытие официального приложения Discord.
- Нет встроенных браузеров и хранения паролей/токенов.

## Ограничения
Это менеджер заметок о профилях, а не мультиклиент Discord. Он не входит в аккаунты, не подключает голосовые каналы, не управляет микрофоном/звуком и не создаёт независимые голосовые соединения. Официальный Android-клиент Discord не предоставляет сторонним приложениям API для этого.

## Получить APK через облачную сборку GitHub Actions
1. Создайте репозиторий на GitHub (можно Private).
2. Распакуйте архив и загрузите **содержимое папки `DiscordMobileManager`** в корень репозитория. В корне должны быть `settings.gradle.kts`, `build.gradle.kts`, папка `app` и `.github`.
3. Откройте репозиторий на GitHub → вкладка **Actions**.
4. Выберите workflow **Build Android APK** → **Run workflow** → **Run workflow**.
5. Дождитесь зелёной галочки. Откройте завершённый запуск, прокрутите до **Artifacts** и скачайте `DiscordMobileManager-debug-apk`.
6. Распакуйте скачанный ZIP. Внутри будет `app-debug.apk`.
7. Передайте APK на телефон и откройте его. Android может попросить разрешить установку приложений из этого источника.

Workflow использует GitHub-hosted runner и собирает debug APK. Сборка не требует Android Studio на вашем ПК. Для облачной сборки нужен аккаунт GitHub; публичные и приватные репозитории поддерживаются с учётом лимитов GitHub Actions.

## Сборка локально
Откройте папку проекта в Android Studio и выполните **Build → Build APK(s)**.

## Параметры
- Application ID: `com.example.discordmobilemanager`
- Min SDK: 26 (Android 8.0)
- Compile/Target SDK: 35
- Язык: Kotlin

Не вводите в это приложение пароли, токены или резервные коды Discord. Для авторизации используйте только официальный клиент Discord.
